# Побег из Светофора

Текстовый квест на Python: вы очнулись в магазине «Светофор»,
где полки забиты банками с человечиной, а по отделу игрушек
бродит голодный Татата Саур. Найдите способ выбраться живым.

## Установка и запуск

Сторонних зависимостей нет — нужен только Python 3.8+.

```bash
git init
git add README.md
git commit -m "первая фиксация"
ветвь git -M main
git remote add origin https://github.com/ilyadragonboard-coder/escape-svetofor.git
git push -u origin main
```

## Управление

- Вводите номер действия из списка и нажимайте Enter.
- `i` — показать инвентарь.
- `q` — выйти из игры.
- Некорректный ввод не ломает игру — программа попросит повторить.

## Структура проекта

```
main.py              — точка входа
game/
  __init__.py        — публичный API пакета
  state.py           — глобальное состояние (инвентарь, флаги)
  art.py             — ASCII-графика
  utils.py           — пауза, очистка экрана, обработка ввода
  locations.py       — локации (по функции на локацию)
  game.py            — стартовый экран и запуск
requirements.txt     — зависимостей нет
```

## Как это устроено

- Одна функция на локацию (`canned`, `toys`, `dairy`, ...).
- Локации вызывают друг друга напрямую — это косвенная рекурсия.
- Инвентарь и «взятые» предметы хранятся в `state.py` в списке и словаре.
- Есть несколько путей к победе и много способов погибнуть.

## Возможные пути к победе

1. Найти ключ в подсобке → открыть дверь на выходе.
2. Найти наличку на складе → отдать кассирше.
3. Выпить «Чудо» — небольшой шанс проснуться (это был сон).
