# Побег из Светофора

Текстовый квест на Python.

Вы очнулись в магазине «Светофор», где полки забиты банками
с человечиной, а по отделу игрушек бродит голодный Татата Саур.
Исследуйте локации, собирайте предметы, читайте записки — и
попробуйте выбраться живым.

## Требования

- Python 3.8 или новее.
- Сторонних библиотек **не требуется** — только стандартная
  библиотека Python (см. `requirements.txt`).

## Установка и запуск

Клонируйте репозиторий и запустите игру:

```bash
git clone https://github.com/ilyadragonboard-coder/escape-svetofor.git
cd escape-svetofor
python main.py
```

Если `python` не срабатывает — попробуйте `python3 main.py`.

Также в папке `escape-svetofor/dist` есть файл `main.exe` чтобы не запускать `main.py`.

Ничего дополнительно устанавливать не нужно.

## Управление

| Клавиша | Действие |
|---|---|
| `1`–`N` + Enter | Выбрать пункт меню |
| `i` | Показать инвентарь |
| `j` | Показать журнал найденных записок |
| `h` | Помощь |
| `q` | Выйти из игры |
| `s` | Включить/выключить звук |

Некорректный ввод (буквы, пустая строка, числа вне диапазона)
не ломает игру — программа попросит повторить.

## Звук

Игра умеет проигрывать тематические звуки (вход в локацию, еда,
бой, смерть, победа, найденные записки и предметы, сигнализация).
Реализовано через стандартный модуль `winsound` — он есть **только
на Windows**, поэтому:

- на Windows звук работает сразу, ничего ставить не нужно;
- на Linux/macOS звук отключается автоматически, игра идёт как обычно;
- включить/выключить звук можно клавишей **`s`** в любом меню;
- текущее состояние звука показано на стартовом экране.

Звуки играются в отдельном потоке и не тормозят сюжет.

## Структура проекта

```
escape-svetofor/
├── main.py              — точка входа
├── requirements.txt     — зависимостей нет
├── README.md            — этот файл
└── game/
    ├── __init__.py      — публичный API пакета
    ├── state.py         — изменяемое состояние (инвентарь, флаги, журнал)
    ├── art.py           — ASCII-графика (логотип, локации, финалы)
    ├── utils.py         — пауза, очистка экрана, ввод игрока
    ├── locations.py     — локации (по функции на локацию)
    └── game.py          — стартовый экран и запуск
```

## Как это устроено

- **Одна функция на локацию** — `canned`, `toys`, `dairy`, `staff`,
  `warehouse`, `security`, `cashier`, `toilet`, `exit_room`.
- **Косвенная рекурсия** — локации вызывают друг друга напрямую:
  `canned → toys → dairy → toys → ...`. Все переходы сделаны
  через `return some_location()` — после завершения партии стек
  разматывается чисто, лишние действия не выполняются.
- **Инвентарь и изменяемый мир** хранятся в `game/state.py`:
  `inventory` (list), `taken_items` (dict), `read_notes` (list),
  `flags` (dict), `game_over` (bool).
- **Журнал записок** — 6 записок спрятаны по локациям и раскрывают,
  что произошло в магазине. Их можно перечитать по `j`.
- **Несколько концовок** — три победы и множество способов погибнуть.

## Возможные пути к победе

1. Найти ключ в подсобке → открыть дверь на выходе.
2. Найти наличку на складе → отдать кассирше.
3. Выпить «Чудо» — небольшой шанс «проснуться».
